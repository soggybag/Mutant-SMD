# Mutant SMD

A redesign of the **Mutant generative synth** (MeeBleeps, https://github.com/Meebleeps/MeeBleeps-Mutant-Synth), based on the Eurorack version in `~/Documents/Arduino/projects/Mutant_Generative_Arduino_Synth/` (Instructables "Mutant Generative Arduino Synth").

**Goals:**
- **One board, three uses:** bare, behind a Eurorack panel, or in an enclosure.
- **Board ≤ 100 mm** (the original is 65.3 × 106.4 mm), for JLC's price break.
- **SMD parts** for JLC assembly; panel parts hand-soldered.
- **Tayda A-8796 round buttons** (as on GlitchStorm v3).
- **Same control positions** as the original, so its front panel still fits.
- No front panel design for now.

**Status:** schematic + PCB v1.0, routed, DRC 0, parity clean, JLC files in production/. 2026-10-19: matrix supply filter added (R8 2.2 Ω + C16 100µ tantalum → V5M), re-routed. Not ordered yet.

- Schematic: [docs/MutantSMD_schematic.pdf](docs/MutantSMD_schematic.pdf), generated by `scripts/build_mutant.py`.
- Notes: [docs/Design Notes.md](docs/Design%20Notes.md).
- Firmware: the original `Mutant_Updated` (Mozzi 2) runs unchanged; the pin map is identical.
